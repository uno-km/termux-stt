3. Memory Footprint & Thermal Safety

Under continuous batch execution, termux-stt maintains a memory footprint between 5.75 MB and 48.2 MB, consuming less than 14% of Android's Low Memory Killer (LMK) threshold (350 MB), ensuring zero background process eviction.
