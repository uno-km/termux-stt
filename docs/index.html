Termux-STT

Unified On-Device Speech-to-Text & Pure Python 128d X-Vector Speaker Diarization

1-Line Quick Installation

Install the official package directly into your runtime:

pip install termux-stt
# or: npm install termux-stt

The Engineering Challenge

Transcribing and diarizing multi-speaker conversations on edge devices typically demands heavy PyTorch runtimes (>2GB) and severe GPU memory consumption.

The Architectural Breakthrough

Integrates Whisper.cpp, Vosk, and Sherpa-ONNX with a closed-form pure-Python 128-dimensional X-Vector clustering algorithm that operates in under 80MB RAM.

Key Capabilities & Built-in Hardening

Triple STT Engine Integration

Seamlessly switches between Whisper.cpp (accuracy), Vosk (latency), and Sherpa-ONNX.

Pure Python Speaker Diarization

Lightweight cosine spectral clustering without external ML frameworks.

Zero Cloud Egress Audio Privacy

Audio processing and transcription execute strictly on-device without cloud network calls.

Supported Compute Kernels & Operations

Subsystem Category Operations & Kernels Status
Speech Recognition Whisper.cpp (tiny/base/small), Vosk Kaldi, Sherpa-ONNX Production
Speaker Diarization 128d X-Vector Extraction, Cosine Spectral Clustering Production
Audio Runtimes Android AudioRecord, WAV/PCM Stream, Real-Time VAD Production

Canonical Usage Example

import termux_stt as stt

# 1. Transcribe audio with speaker diarization
engine = stt.STTEngine(model="whisper-tiny")
result = engine.transcribe_with_diarization("meeting.wav")

for seg in result.segments:
    print(f"[{seg.speaker}] ({seg.start:.1f}s - {seg.end:.1f}s): {seg.text}")

import { STTEngine } from "termux-stt";

const engine = new STTEngine({ model: "whisper-tiny" });
const result = await engine.transcribe("meeting.wav");
console.log("Transcript:", result.text);
